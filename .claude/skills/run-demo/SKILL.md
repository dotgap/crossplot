# Run and verify the dinosaur demo

The demo is a Vite app in `examples/dinosaurs`. It imports the packages from their built `dist/`,
so package changes need `pnpm build` first (the demo's `dev` and `build` scripts do this for you).

## Run it

```sh
pnpm install
pnpm demo                         # pnpm -w build, then the Vite dev server (http://localhost:5173)
```

For a check that matches production (and CI), build and preview instead:

```sh
pnpm --filter dinosaurs build
pnpm --filter dinosaurs preview --port 4173 --strictPort    # run in the background
```

The engine runs in a Web Worker, so open the page over HTTP, never as a `file://` URL.

## Verify it in a headless browser

`scripts/smoke.cjs` loads the page, waits for the charts, brushes the age timeline, and reports
the chart count, the selection count before and after the brush, the URL hash (filter state lives
there), any console or page errors, and saves a full-page screenshot.

```sh
node .claude/skills/run-demo/scripts/smoke.cjs http://localhost:4173/ /tmp/demo.png
```

It needs Playwright with Chromium. In cloud containers it is preinstalled and `require("playwright")`
works anywhere (don't install another version). Elsewhere, install it in a scratch folder
(`npm i playwright && npx playwright install chromium`) and run the script with
`NODE_PATH=<scratch>/node_modules`.

A healthy run looks like:

```
charts 16 total: Showing all 21,253 finds. Drag or click any chart to narrow it down.
after brush: Showing 5,015 of 21,253 finds: from 161 to 120 million years ago. hash: #{"age":{"range":[120.48,160.82]}}
errors []
```

Then look at the screenshot: axes readable, nothing clipped, the brushed range highlighted and the
other charts re-aggregated, with dashed outlines showing the unfiltered shape. Check both light and
dark color schemes when you change styles. If you changed the page layout or chart ids, update the
selectors in `smoke.cjs` (`#sentence`, `#age`, `.crossplot-chart`).

When done, stop the preview server. If the screenshot is for a person, take it at
`deviceScaleFactor: 2`.

## Data

`public/dinosaurs.json` is generated by `pnpm --filter dinosaurs data` (`scripts/prepare-data.mjs`)
from Paleobiology Database exports, plus each find's ancient position from the GPlates Web Service.
`public/coasts.json` (today's land and ancient coastlines for the map) comes from
`scripts/prepare-coasts.mjs`. Both scripts take saved files as arguments; paleobiodb.org and
gws.gplates.org are blocked from cloud sessions, so download on a local machine. Only rerun them when
the data shape needs to change.
